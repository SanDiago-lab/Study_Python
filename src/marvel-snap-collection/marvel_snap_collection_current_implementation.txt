## 4. PythonアプリへのUntapped同期

DownloadsフォルダをPythonから参照する仕組みを実装済み。

使用するパス：
```python
DOWNLOADS_DIR = Path.home() / "Downloads"
UNTAPPED_JSON_FILE = DOWNLOADS_DIR / "untapped_collection.json"
```

「Untappedから同期」ボタンで、ファイル選択ダイアログを使わずにJSONを読み込める。

同期時：
- Untapped JSONからカード一覧を取得
- `collection.json`のカード一覧を更新
- 同期日時を更新
- CLは既存値を維持
- カード数を画面に表示

実際にUntapped JSON → Pythonアプリ → `collection.json` → CSVの一連の処理が正常動作することを確認済み。

## 6. 同期差分・履歴

同期前後のカード数を比較する処理を実装。
- `old_cards`
- `new cards`
- `old_count`
- `new_count`
- `difference`

を利用。

カード名の集合を比較して新規取得カードを特定：
```python
old_names = {
    card.get("name")
    for card in old_cards
    if card.get("name")
}

new_names = {
    card.get("name")
    for card in cards
    if card.get("name")
}

added_cards = sorted(new_names - old_names)
```

同期履歴には以下を保存する実装を追加済み：
- `sync_time`
- `collection_level`
- `card_count`
- `added`
- `added_cards`

同期履歴をJSONへ追加する処理まで実装・案内済み。
